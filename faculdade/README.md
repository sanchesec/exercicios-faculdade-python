# Exercícios da Faculdade

Esta pasta reúne exercícios e atividades desenvolvidos durante minha graduação em Engenharia de Computação.

Os arquivos estão organizados por aula e representam minha evolução nos fundamentos de programação e lógica utilizando Python.

## Conteúdos praticados

Ao longo dos exercícios, são trabalhados conceitos como:

* Entrada e saída de dados
* Variáveis e tipos de dados
* Operadores matemáticos e lógicos
* Estruturas condicionais
* Laços de repetição
* Funções
* Listas
* Resolução de problemas com lógica de programação

## Organização

Cada pasta corresponde a uma aula ou conjunto de exercícios realizados durante o curso.

O código é mantido como registro do meu aprendizado e da minha evolução ao longo da graduação.
