# Desafios

## Loja de Tintas

Programa que calcula a quantidade e o custo de tinta necessários para pintar uma determinada área.

### Regras

* 1 litro de tinta cobre 6 m²
* Lata de 18 litros: R$ 80,00
* Galão de 3,6 litros: R$ 25,00
* Acréscimo de 10% de folga
* Cálculo de três opções:

  * apenas latas
  * apenas galões
  * combinação de latas e galões com menor desperdício

Arquivo: `paint_store.py`
